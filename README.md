# DSA with C++

A collection of **Data Structures and Algorithms (DSA)** programs implemented in **C++**.

This repository contains my practice, implementations, and solutions while learning DSA and preparing for coding interviews and placements.

---

## 📚 Topics Covered

- Arrays
- Strings
- Linked Lists
- Stacks
- Queues
- Binary Trees
- Binary Search Trees
- Recursion
- Searching Algorithms
- Sorting Algorithms
- Object-Oriented Programming
- And more...
